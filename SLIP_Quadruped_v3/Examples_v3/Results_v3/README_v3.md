# Round 4 quadruped production-study artifacts

`QuadrupedalContinuationStudy_v3` writes
`Round4_Quadruped_Production_Study_v3.mat` here after an actual MATLAB run.
The artifact stores plain numerical structures: solver counters, accepted and
rejected continuation points, topology signatures, physical-search outcomes,
and external Floquet step-grid data. It does not store prescribed event times
or gait labels.

The MAT file is evidence only for the MATLAB version and platform recorded
inside it. Re-run the study instead of treating a cached artifact as a general
proof of convergence on another platform.
