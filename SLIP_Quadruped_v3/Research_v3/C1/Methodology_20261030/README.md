# Retained method provenance

Use the current public `ContinuePeriodicBranch_v3` workflow, described in
`../../../Docs_v3/Reusable_Branch_Continuation_v3.md`, for new searches.
Historical private wrappers contain expired clocks, fixed paths and old
source epochs; they are source evidence, not runnable current campaigns.

- `c1_final_methods_20261030.tar.gz` and `SHA256.json`: original seven-method
  source/configuration provenance.
- `Retired_Private_Method_Sources_20261105.zip`: 78 retired private MATLAB
  methods and their literal source index.
- `Historical_Method_Epoch_Sources_20261105.zip`: historical MATLAB sources,
  beforeimages and patches from the old loose method tree, with exact hashes.

The November 5 consolidation intentionally removes repeated installation,
per-copy custody and construction detail. Numerical results and essential
scientific audits are retained separately. The source packs do not restore
all retired dense data or guarantee byte-for-byte replay of old experiments.
See `../Audits/V3_Methodology_Consolidation_20261105.json` for exact removals.
