## Individual body-relative suspension posture

For each positive-duration physical flight, the classifier observes the maximum COM height on the closure of the interval, using the flight-side state limit. Native dimensionless gravity is obtained from `ContinuousDynamics_v3` in all-swing mode (the current equations give g=1). For interval `[a,a+D]`, it uses `a+clip(vy(a+)/g,0,D)`. An interior maximizer is recorded as `interior_apex`; an endpoint maximum is recorded as `boundary_maximum` and is never described as an apex. An exact saved flight-side state retains its raw values. Between saved knots, native all-swing `ode45` flow is evaluated from both ends of the smooth bracket, and a forward step-halving check is performed. Per-angle numerical uncertainty is ten times the largest forward/backward discrepancy, step-halving discrepancy, or roundoff floor. G/E/M signs and the principal chart require that uncertainty margin; unresolved evaluations yield U. The default observation integration is `RelTol=1e-11`, `AbsTol=1e-13`, `MaxStep<=0.001` with a finer halved step and tenfold tighter tolerance. This is registered numerical sensitivity, not a rigorous interval bound, and remains separate from fine independent physical replay.

The raw principal chart is strictly `-pi < alpha < pi`. Within it, the foot-minus-hip vector projected onto the torso forward axis equals `leg_length*sin(alpha)`, so the sign of the raw relative angle agrees with the projected foot direction. The classifier never wraps a dynamical state to manufacture signs. With `GeometryTolerance=1e-5` radians:

- G: each hind alpha is positive above tolerance and each fore alpha is negative below minus tolerance.
- E: each hind alpha is negative below minus tolerance and each fore alpha is positive above tolerance.
- M: every angle sign is resolved, but the four individual inequalities do not give G or E.
- U: near-zero boundaries, an out-of-chart angle, missing observation data, or unresolved uncertainty.

World-relative angles `phi+alpha`, pitch, pitch rate, touchdown order, pair averages, and aggregate front-minus-hind spread do not determine G/E. The reference flight contains the canonical marked apex at the initial section. If that section is grounded, the first subsequent flight in the fixed cyclic ordering is used and the choice is recorded. The initial section is checked for `dy=0` and downward acceleration. The complete cyclic per-flight vector and its phase identities are stored. A `[G,E]` two-flight cycle may receive BG2 when its reference flight is G; the other flight need not share its geometry. A boundary maximum may receive G/E from its individual signs.

## Optional BL-marked return policy

The existing `EventCycleReturnPolicy_v3` remains the quadruped default for compatibility. It selects a labelled cycle with at least one TD/LO per leg and mode closure; it does **not** certify a primitive period. Use the independent primitive diagnostics for that question.

`BLMarkedApexReturnPolicy_v3` can instead be passed explicitly to `PoincareMap_v3`. The initial chart requires that the next BL touchdown occur strictly between the initial downward apex and the next downward apex. The selected apex is consequently the last qualifying apex strictly before that touchdown, with no intervening BL touchdown. A first-return lookahead uses the same autonomous system, simulator and geometric section for this predicate. The rule applies to nearby nonperiodic initial states without evaluating a periodic residual. Its default return has exactly one intervening BL touchdown; `BLTouchdownsPerReturn=N` explicitly selects an iterated labelled return. Each candidate must satisfy the same next-TD marking and, by default, right-continuous mode closure. Neither a state-distance test nor a target gait label changes this map.

The map propagates the section chart, mode, downward orientation, selected initial/return BL occurrences, apex return multiplicity, post-reset ownership, elapsed time, translation gauge and positive marking separation margins into the return info and `HybridOrbit_v3`. Lookahead integration is part of its computational cost and uses explicit limits. An occurrence passed before a qualifying apex, BL TD/apex coincidence, absent next apex, lost transversality or changed event identity is a local chart boundary or failure. The strict-before chart deliberately does not silently reinterpret BL touchdown coincident with a section crossing; the general geometric return still processes such contact clusters using its existing post-reset convention. Grounded apexes are eligible whenever their physical mode and downward transversality are admissible.
