# Legacy initial guesses

`Source_Fixtures` contains the original eight v2 branch datasets. `Converted_Seeds` contains the byte-preserved C1-named native-coordinate conversions, their conversion manifest and completion receipt.

These are initial guesses, not admitted strict-v3 branches. The documented autonomous validation failures remain in the [model compatibility report](../../../Docs_v3/Legacy_P1_Seed_Recovery_and_Model_Compatibility_v3.md), with final summary MAT/JSON evidence indexed in [Scientific_Evidence](../../../Audits_v3/Scientific_Evidence/README.md). Folder selection deliberately keeps these guesses separate from the accepted P1 catalog.
